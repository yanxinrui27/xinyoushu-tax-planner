## 建议测试顺序

1. 依次导入四个案例，每次先观察收入总览。
2. 进入月度精算，核对月份颜色、图例、当月及累计扣缴去向。
3. 进入年度快算，核对取数方式、截止月份、确认框和结果页。
4. 进入专项扣除申报台账和个税筹划，核对项目名称、金额与方案数量。
5. 完成后导入自己的备份恢复数据。
