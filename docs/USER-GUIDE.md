# 用户使用指南

本文说明如何从第一次打开网页开始，完成收入录入、扣除发现、年度汇总、筹划比较和数据备份。

## 1. 直接打开网页

获得公开链接后即可直接进入工作台，不需要登录 GPT、GitHub，也不需要注册用户名或设置密码。

输入的工资和扣除记录只保存在当前网址对应的浏览器本地存储中。公开访问不代表数据会公开上传，但本地记录本身没有加密；请勿在公共电脑或不受信任的共享设备上长期保存真实数据。

## 2. 选择录入方式

### 月度精算

适合希望看清每月到手和累计扣缴的人。

1. 在页面顶部选择月份。
2. 填写基本工资、奖金、加班费、应税补贴和税前工资扣减。
3. 核对社保、公积金基数及比例。基数留空时默认使用基本工资。
4. 选择并填写其他依法确定的扣除。
5. 选择“已发生”或“预测”，确认后查看结果。

月份状态的颜色含义：

- 绿色：已经发生；
- 蓝色：预测收入；
- 黄色：尚未填写。

保存全部 0 元表示已经确认该月没有收入；未保存表示缺少数据，两者不会混为一类。

### 年度快算

适合已经掌握年度合计，或只希望汇总到当前月份的人。

- **从月度记录汇总：** 选择截止月份，系统读取 1 月至截止月的连续完整记录。后续月份无需填写。
- **自行填写年度金额：** 直接填写年度工资、个人社保公积金、养老金及其他金额。

两种方式独立保存。年度自行填写不会生成月度工资，月度汇总也不会覆盖原始记录。

## 3. 使用“政策找人”

依次回答子女与照护、赡养老人、住房、继续教育和大病医疗相关问题。系统会把结果分为：

- 建议核对；
- 信息不足；
- 与现有台账冲突；
- 当前未发现。

“建议核对”不代表已经取得申报资格。请根据页面列出的条件、材料、家庭分配和适用月份自行核实，再预填到专项扣除申报台账。

## 4. 核对专项扣除申报台账

台账记录的是个人可以扣除的金额，并不一定等于实际现金支出。每条记录包括：

- 扣除项目与对象标记；
- 起止月份；
- 个人可扣金额；
- 基准已有或备选新增；
- 工资预扣或仅年度汇算；
- 资格是否已经确认。

未确认的基准扣除会暂停正式年度结果。未确认的备选扣除不会进入方案比较。

## 5. 查看结果与筹划方案

### 月度结果

结果页展示预计到手、收入、社保公积金、税款、到账调整、累计计税过程，以及当月和累计资金去向。

### 年度结果

结果页展示税前收入、个人社保公积金、专项附加扣除、其他依法扣除、最终个税、可支配现金和可能的汇算差额。

### 个税筹划

系统在当前输入范围内比较：

- 奖金并入综合所得或符合条件时单独计税；
- 是否使用全部已确认的备选新增扣除；
- 是否在预算内增加个人养老金缴费。

页面会同时给出税款最低和可支配现金最高的方案。个人养老金是受限资金，不能只看少缴税额；预测收入、资格或金额改变后，应重新计算。

## 6. 导出和恢复数据

进入“设置与备份”：

- **导出完整备份：** 保存当前年度的 JSON 数据，用于恢复或迁移。
- **导入备份：** 校验后替换同一年度记录，其他年度保留。
- **导出 CSV：** 导出当前月度或年度模式的明细。

备份文件包含敏感工资信息，请保存到受保护的位置，不要提交到公开 GitHub 仓库。

换浏览器、设备或域名时，直接打开新网址并导入原备份即可。

## 7. 公开访问与本机记录

网页没有登录和退出流程。关闭页面后，已保存记录仍会留在当前浏览器；再次打开同一网址即可继续使用。若在共享设备上录入过数据，请先导出需要的备份，再通过浏览器的网站数据设置清理该网址的本地存储。

## 8. 常见问题

### 为什么年度结果显示“待补齐”？

月度汇总范围内存在未填写月份、基准扣除尚未确认，或适用范围没有确认。根据页面顶部提示补齐即可。

### 为什么扣除金额不等于少缴税额？

扣除金额只减少应纳税所得额，实际少缴税额还取决于适用税率。页面会分别展示两者。

### 是否需要登录 GPT 或 GitHub？

不需要。GitHub Pages 提供的是公开网页，任何获得链接的人都可以直接打开。GPT 或 GitHub 登录状态不会影响工具使用。

### 网页结果能否直接用于报税？

不能。工具用于测算、核对和发现可能遗漏的信息，实际申报应以个人所得税 APP、有效凭证和税务机关口径为准。
