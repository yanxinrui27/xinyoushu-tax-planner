# 用户使用指南

本文说明如何从第一次打开网页开始，完成扣除发现、收入录入、申报台账核对、筹划比较和数据备份。

## 1. 登录或创建本机账号

打开[线上版本](https://yanxinrui27.github.io/xinyoushu-tax-planner/)后会看到登录页。

- 想先查看完整效果：使用公开演示账号 `yanxinrui`，密码 `12345678`。登录页已经预填这组信息。
- 想填写自己的数据：选择“创建自己的空白账号”，设置当前浏览器使用的用户名和密码。新账号不会带入演示数据。

公开演示账号及案例是产品展示内容，不具有私密性。自建账号只在当前浏览器生效，没有云端同步或密码找回；工资数据本身也未加密。请勿在公共电脑中长期保存真实数据。

## 2. 第一步：发现可能遗漏的扣除

进入“专项扣除发现与管理 → 扣除发现”。四个页面分别覆盖子女与照护、赡养老人、住房与租赁、教育与医疗。

每个页面都分为两个模块：

1. **情况简要问答：** 按页面提示用一段话说明实际情况，选择“智能识别并填充”，核对识别摘要后确认。
2. **结构化信息确认：** 在同一区域内按政策项目分段核对人数、月份、扣除比例和资格状态，再保存本步骤。

![步骤一：扣除发现](screenshots/step-1-discovery.svg)

系统会把结果标为建议核对、信息不足、与现有台账冲突或当前未发现。自动填充只是录入辅助，不代表已经取得申报资格；请结合凭证、家庭分配和税务机关口径确认。

## 3. 第二步：填写收入并测算

进入“月/年收入填写及测算”。

### 月度精算

1. 在页面上方选择月份。
2. 填写基本工资、奖金、加班费、应税补贴和税前工资扣减。
3. 核对社保、公积金基数及比例。页面提供默认比例，支持按实际情况修改。
4. 选择并填写其他依法确定的扣除。
5. 选择“已发生”或“预测”，确认提交后查看结果。

月份颜色区分已发生、预测和未填写。保存全部 0 元表示已经确认该月没有收入；未保存表示缺少数据，两者不会混为一类。

### 年度精算与年度记录

- **从月度记录汇总：** 选择截止月份，读取 1 月至截止月的连续完整记录，后续月份无需填写。
- **自行填写年度金额：** 独立填写年度工资、个人社保公积金、养老金及其他金额。

两种方式独立保存，不会互相覆盖原始记录。

![步骤二：收入填写与测算](screenshots/step-2-income.svg)

## 4. 第三步：核对专项扣除申报台账

进入“专项扣除发现与管理 → 专项扣除申报台账”，核对从扣除发现页面预填的项目，也可以手动新增。

每条记录应确认：

- 扣除项目与对象标记；
- 起止月份；
- 个人可扣金额与家庭分配；
- 基准已有或备选新增；
- 工资预扣或仅年度汇算；
- 资格是否已经确认。

![步骤三：专项扣除申报台账](screenshots/step-3-ledger.svg)

未确认的基准扣除会暂停正式年度结果。未确认的备选扣除不会进入方案比较。

## 5. 第四步：完成个税筹划与设计

### 设置比较条件

填写个人养老金预算、可用备选扣除和奖金计税选择范围。确认收入与台账完整后再生成方案，避免用缺失数据比较。

### 筹划结论查看

系统会比较奖金并入综合所得或符合条件时单独计税、是否使用全部已确认备选扣除，以及是否在预算内增加个人养老金缴费。页面同时显示最终税款、可支配现金、节税额和方案成立条件。

![步骤四：个税筹划与设计](screenshots/step-4-planning.svg)

个人养老金属于受限资金，不能只看少缴税额。收入、资格或金额发生变化后，应重新计算。

## 6. 查看结果

- **月度结果：** 展示预计到手、收入、社保公积金、税款、到账调整、累计计税过程，以及当月和累计资金去向。
- **年度结果：** 展示税前收入、个人社保公积金、专项附加扣除、其他依法扣除、最终个税、可支配现金和可能的汇算差额。

首页会把关键指标、数据状态、下一步操作和流程入口汇总展示，适合每次登录后快速判断还有哪些信息需要补齐。

## 7. 导出和恢复数据

进入“设置与备份”：

- **导出完整备份：** 保存当前账号、当前年度的 JSON 数据，用于恢复或迁移。
- **导入备份：** 校验后替换同一年度记录，其他年度保留。
- **导出 CSV：** 导出当前月度或年度模式的明细。

自建账号不支持跨设备自动同步。换浏览器、设备或域名时，先在旧环境导出备份，再在新环境创建或登录账号并导入。备份文件包含敏感工资信息，请保存到受保护的位置，不要提交到公开仓库或 Issue。

## 8. 常见问题

### 为什么不同设备登录自建账号后没有原来的数据？

用户名和密码只保存在创建它的浏览器中，不是云端账号。跨设备使用时需要在新设备创建账号并导入备份。公开演示账号例外：它的初始虚构案例随网页发布，因此任何设备都可查看。

### 是否需要登录 GPT 或 GitHub？

不需要。网页使用自己的本机登录界面，与 GPT 和 GitHub 登录状态无关。

### 为什么年度结果显示“待补齐”？

月度汇总范围内存在未填写月份、基准扣除尚未确认，或适用范围没有确认。根据页面顶部提示补齐即可。

### 为什么扣除金额不等于少缴税额？

扣除金额只减少应纳税所得额，实际少缴税额还取决于适用税率。页面会分别展示两者。

### 网页结果能否直接用于报税？

不能。工具用于测算、核对和发现可能遗漏的信息，实际申报应以个人所得税 APP、有效凭证和税务机关口径为准。
