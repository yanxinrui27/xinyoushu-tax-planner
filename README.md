# 薪有数 · 个人收入与个税规划

移动端适配的纯前端工具。没有后端，不上传工资数据。演示数据只用于展示；首次使用请建立空白年度并录入本人信息。

[打开在线版本](https://sienna-tax-planner-20261021.amberapple257.chatgpt.site/)

![月度精算测试案例展示](docs/screenshots/monthly-demo.png)

## 快速体验

仓库内置 4 组虚构测试案例，覆盖月度阶段汇总、完整年度奖金与筹划、年度自行填写、缺失月份阻断校验。打开网页后进入“设置与备份”，点击“↑ 导入备份”，选择 [`test-data`](test-data) 中的 JSON 文件即可恢复对应情景。

推荐先导入 `01-月度汇总-截至10月.json`。它会显示 1—9 月“已发生”、10 月“预测”、11—12 月“未填写”三种月份状态，并生成截至 10 月的年度阶段汇总和筹划结果。所有测试金额均为虚构数据。

## 使用

在项目目录执行 `python -m http.server 8765 --directory dist`，在浏览器打开 http://localhost:8765 。ES 模块需要 HTTP 服务，不支持双击 HTML 直接运行。

网页已通过 GitHub Pages 自动发布，公开地址为 [https://yanxinrui27.github.io/xinyoushu-tax-planner/](https://yanxinrui27.github.io/xinyoushu-tax-planner/)。也可以把 `dist/` 部署到 Cloudflare Pages 或 Vercel；具体步骤和数据存放原则见 [`DEPLOYMENT.md`](DEPLOYMENT.md)。

## P0 / P1 功能

- 政策找人：通过子女与照护、赡养老人、住房、继续教育和大病医疗四步问答，主动发现可能遗漏的七项专项附加扣除；结果区分建议核对、信息不足、冲突和未发现，并可一键预填专项扣除申报台账。
- 影响解释：推荐卡分别展示预计年度可扣除金额和按当前收入单项估算的税额变化；收入数据不完整时不猜测税额。每条结果保留政策依据、规则版本和核对日期。
- 两步测算流程：月度精算和年度快算均先填写金额与扣除，确认提交后进入独立结果页；月度页顶部持续显示当前月份。
- 基数比例计算：社保基数默认跟随基本工资，养老8%、医疗2%、失业0.5%、生育0%、工伤0%；公积金默认开启、比例12%，所有基数和比例均可修改。
- 依法扣除分类：支持多选企业/职业年金、税优商业健康保险、税延型商业养老保险及其他有明确依据的项目，逐项填写并校验商业健康保险限额。
- 月度精算：区分未填写、确认零收入、预测和已发生；月份按钮用颜色和图例标明状态；展示工资、社保、公积金、普通工资个税、奖金税和到手金额，并保留当月及累计扣缴去向。
- 年度快算：支持直接汇总1月至指定截止月份的完整月度记录，或自行填写年度合计。阶段汇总不要求覆盖全年，不覆盖月度记录；自行填写的数据也不会反向均摊到各月。
- 专项扣除申报台账：按项目、对象、月份、个人金额、基准或备选、预扣或年度汇算记录；检查额度、重复项目、住房租金与贷款互斥、子女年龄阶段重叠等冲突。
- 方案比较：枚举奖金计税方式、全部已确认备选扣除、预算内个人养老金的所有可用组合；同时比较最终个税与可支配现金，并说明与当前基准的差异及执行条件。
- 奖金临界点：展示单独计税和并入综合所得的税后变化，精确列出最近临界点前后 0.01 元及多 1 元的结果。
- 数据管理：分年度保存在浏览器，支持月度/年度 CSV、完整 JSON 备份及恢复。旧版升级前保存原始快照；旧扣除合计须分类确认后才进入正式计算。

## 数据完整性

未填写月份不会按 0 元处理。任一月份缺失，或基准扣除尚未分类确认时，缺口之后的累计预扣、全年税款和推荐暂停输出。全年完整数据还需确认适用范围，才会生成个人方案。已发生月份可填写工资条实际普通工资税额；留空时明确标为系统预测。

## 适用范围

支持 2026、2027 年度，中国内地居民从年初在同一单位取得普通工资薪金及符合条件的全年一次性奖金场景。暂不支持换工作、多单位、劳务报酬、境外或经营所得、减免税、特殊预扣及回款/提成优化。工具检查可表达的金额和冲突，但不自动判断真实资格；结果需与个人所得税 APP、凭证和税务机关口径核对。

新增年度扣除和个人养老金方案影响全年最终税额，不模拟具体执行月份。个人养老金不预测投资收益或未来领取税额。本机记录会随浏览器数据清理而丢失，请定期导出备份；备份包含敏感工资信息，请妥善保存。
