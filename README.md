# 薪有数 · 个人收入与个税规划

移动端适配的纯前端工具。没有后端，不上传工资数据。演示数据只用于展示；首次使用请清空并录入本人信息。

## 使用

在项目目录执行 `python -m http.server 8765 --directory dist`，在浏览器打开 http://localhost:8765 。ES模块需要HTTP服务，不支持双击HTML直接运行。

## 支持功能

- 工资、社保分项、公积金、个税与到手金额。
- 当月及年内累计扣缴明细、十二个月预测。
- 实际税额与预估税额分开记录，历史修改重算。
- 全年一次性奖金两种计税方式比较。
- 已确认年度扣除与养老金新增缴费情景。
- 分年度本地保存、CSV导出、JSON备份恢复。

## 范围

2026、2027年度，中国内地居民从年初在同一单位取得普通工资薪金场景。年中使用请逐月补录。未实现换工作、多单位、劳务报酬、减免税及特殊预扣办法。不自动判断扣除资格。政策来源见页面设置页。

所有月度默认预测；真实扣税需标记为已发生并填写工资条数额。方案中新增年度扣除、养老金缴费影响全年最终税额，不模拟执行月份。养老金不预测投资回报或未来领取税额。

本机存储会随浏览器清理而丢失，请导出备份。备份包含敏感工资信息，请妥善保存。

## 验证

`node test.mjs` 运行计算规则测试。源码在dist目录，无需构建，无第三方依赖。
